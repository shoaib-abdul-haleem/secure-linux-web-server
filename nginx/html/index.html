Secure Linux Web Server

This page is served by Nginx over HTTPS on Ubuntu Server in a VirtualBox home lab.

Diese Seite wird von Nginx über HTTPS auf einem Ubuntu Server in einem VirtualBox-Homelab ausgeliefert.

  • Firewall: UFW, only ports 22, 80 and 443
  • TLS 1.2 and 1.3, HTTP redirects to HTTPS
  • SSH hardening and fail2ban
